Ген альбинизма OCA2

Основные параметры BLAST:
- Program: blastn
- Database: Core nucleotide database (core_nt)
- Program selection: More dissimilar sequences (discontiguous megablast)
- Query sequence type: nucleotide sequence
- Organism filter: использовались отдельные поиски по разным таксономическим группам
- Excluded organisms: Homo sapiens исключался из поиска, чтобы не получать человеческие последовательности
- Exclude uncultured/environmental sample sequences: включено, чтобы убрать неинформативные environmental-записи
- Max target sequences: 100
- Остальные параметры алгоритма оставлены по умолчанию

Использованные таксономические фильтры:
1. Primates - для поиска гомолога среди приматов
2. Mammalia с исключением Primates - для поиска гомологов среди других млекопитающих
3. Aves - для поиска гомологов среди птиц
4. Reptilia — для поиска гомологов среди рептилий
5. Actinopterygii  - для поиска гомологов среди рыб

Таблица видов:
в файле species_tables.tsv

Анализ:
Множественное выравнивание OCA2 показывает наличие хорошо выраженных консервативных участков у всех выбранных видов.
Наиболее сходными являются последовательности человека и шимпанзе, что ожидаемо. У других млекопитающих также сохраняется
высокая степень сходства, тогда как у птиц, рептилий и рыб наблюдается больше замен и gap-участков.

Несмотря на это, в центральной части выравнивания сохраняются общие консервативные блоки, например участки около мотивов
`GTGGTGGAGTGGATTGATT`, `ATATTTTCAGAAAC` и `TGATTGCAGAAGT`. Их сохранение у разных групп указывает
на функциональную значимость этих областей гена OCA2. Начальные и конечные области менее консервативны, но это может быть
связано с частичной длиной некоторых найденных последовательностей. В целом выравнивание подтверждает гомологичность
выбранных последовательностей OCA2.

Объединяющий таксон:
Ближайший общий таксон для выбранных видов, включая человека - Euteleostomi, или костные позвоночные.
Этот таксон объединяет лучепёрых рыб и четвероногих позвоночных, включая млекопитающих, птиц и рептилий.
