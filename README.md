Фенотип: альбинизм. ALBINISM, OCULOCUTANEOUS, TYPE II; OCA2  
Это наследственное нарушение синтеза меланина, которое приводит к сниженной пигментации кожи, волос и глаз.
Основные проявления включают светлую окраску, нарушения зрения и повышенную чувствительность к солнечному свету. 
Заболевание генетически гетерогенно, то есть может быть вызвано мутациями в разных генах.

Подтипы и связаные гены:  
TYPE II; OCA2 -> ген OCA2  
TYPE IA; OCA1A -> ген TYR 

Оценка качества выравниваний
1. Ген TYR  
Для TYR результат Water лучше по качеству: процент идентичности выше - 76.6% против 26.8% по Needle, 
доля пропусков меньше - 8.7% против 68.0% по Needle и score немного выше - 6391.5 против 6387.5 по Needle.
Кроме того, в выравнивании Needle видно большое количество длинных участков из gap-символов, особенно в конце,
что указывает на плохое глобальное сопоставление последовательностей.

2. Ген OCA2  
Здесь результаты Needle и Water очень близки, но Water всё же немного лучше:
у него чуть выше идентичность - 74.1% против 73.5% по Needle,
меньше gaps - 9.5% против 10.3% по Needle и немного выше score - 9132.5 против 9126.5 по Needle. 
При этом длина выравнивания почти такая же, как у Needle, то есть локальное выравнивание в данном случае охватывает 
почти всю значимую часть последовательностей.
